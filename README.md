A one-line, one-star review written by a houseplant about the human who owns it. The plant's grievance: its human bought a moisture meter, checks it every morning, then waters it anyway — so it has been drowning since March in a pot with no drainage hole while the human tells guests it is thriving.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes the 191-character review to `$MAKEFUN_OUTPUT_DIR/entry.txt`, using only the Python standard library. The output is deterministic: the same bytes on every run.
